# 个人主页 · index.html

单文件静态页，无依赖、无构建。双击 `index.html` 就能看。

## 待填清单

页面上**浅桃色底**的文字都是待填。填完把 `<span class="tbd">` 这层壳去掉即可（或者整个删掉 class，底色就没了）。

| 位置 | 字段 | 建议长度 | 备注 |
|---|---|---|---|
| `<title>` / `og:*` | 名字、一句话介绍 | 30 字内 | 分享到微信/X 时显示 |
| 顶部 .brand | 名字 | 2–6 字 | 中文或英文都行 |
| .eyebrow | 城市 · 届别 · 当前状态 | 15 字内 | 例：杭州 · 2027 届 · 找产品实习 |
| 首屏 h1 | 一句话定位 | 12–20 字 | 两行，第二行斜体 |
| .lede | 支撑这句话的三句事实 | 60–80 字 | 不要形容词，要事实 |
| .links | 邮箱 / X / GitHub / 简历 PDF | — | 简历 PDF 放到同目录，改 href |
| 01 关于 | 两段自我介绍 | 各 60–80 字 | 第一段：在做什么；第二段：怎么做判断 |
| 02 经历 | 3 条时间线 | 每条 40 字 | 项目/角色 + 一行可验证结果 |
| 03 主项目 | 项目名 + 一句话 | 20 字内 | 挑最能说明判断力的那个 |
| 03 主项目 | 问题 / 判断 / 做了什么 / 结果 / 为什么停 | 每项 30–60 字 | 「为什么停」不要省 |
| 03 指标 | 3 个数字 | — | 没有数字就删掉整个 `.metrics` 块 |
| 03 其他项目 | 3 条 | 每条 20 字 | 一句话 + 为什么停 |
| 04 写的东西 | 1–2 篇 | — | 没有就删掉整个 `<section id="writing">` |
| 05 联系 | 一句话 + 三个链接 | — | |
| footer | 最后更新日期 | — | |

## 改样式

所有颜色、字体、间距在文件顶部 `:root{}` 里。改一个变量全站生效。

- 底色：`--cream`
- 卡片：`--cream-light`
- 正文黑：`--ink`
- 强调色：`--green`（钱/正数）、`--orange`（标签）

## 断点

- ≤767px：单列、标题换短版、卡片内边距收紧
- 768–1200px：与桌面一致（容器最大 720px）
- 字号全局在 `h1`、`.card h2`、`.tl h3` 上
